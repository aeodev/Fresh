What this lab reproduces, and what it doesn’t

Why dashboard Test Chat is different

Test Chat calls drafting directly. Here, an iframe stores a customer message in a provider, a separate notification wakes Fresh QA, and the Worker re-reads the provider API before sending as the reply agent.

Real application code

The actual Fresh QA event parser, Worker routes, D1 migrations, Durable Object debounce and queue, knowledge retrieval, AI prompt, confidence gate and Freshchat REST client run unchanged. Real AI requests use your local OpenAI key.

Simulated Freshworks infrastructure

The widget, provider REST server and notification delivery are local substitutes. Their routes and payloads follow Freshworks’ published interfaces. This does not certify the hosted SDK, Freshworks event service, account permissions or production delivery.
